月度利润计算工具

启动 dist 文件夹中的“ProfitTool.exe”或桌面“月度利润计算工具”快捷方式，无需安装 Python 或 Excel。
1. 分别选择订单、商品基础信息、未结算、已结算、成本五个文件；也可将每个文件拖入对应的输入框，支持中文和空格路径。
2. 点击“识别订单月份”，选择日期依据和月份。默认订单创建时间。
3. 填写“当月运费收入”合计及币种、“当月预计退款比例”（填10表示10%，默认10），点击“计算利润”。
4. 点击“导出 Excel 报告”，包含利润明细、SKU汇总、利润合计、异常清单、计算说明。
5. 点击“清空记录”清除本次计算结果和异常日志，保留导入文件、月份和输入参数，不删除源文件或已导出的报告。计算过程中暂不执行清空。
异常日志展示全部记录，区分商品SKU缺失、货号格式无效、结算组合缺失、数值错误及成本匹配问题，附标识、可用源行和核对建议。

计算口径
单件总成本 = FOB采购价 + 头程费用 + 尾程运费 + 处理费 + 美仓仓储费 + 预计退款成本 + 资金成本。
美仓仓储费 = 申报价格 × 美仓仓储费率。
预计退款成本 = 申报价格 × 当月自定义退款比例。不再读取成本表Y列，不再导出原R列退款乘数、原S列运费收入。
资金成本 = 申报价格 × 资金成本率。
利润 =（申报价格 - 单件总成本）× 件数。
最终利润 = 利润合计 + 手填当月运费收入；运费仅加一次，不乘件数、不分摊到SKU，不再读取成本表 AA 列。
修改运费后需重新计算，再导出报告。各项费率不重复加入总成本。内部使用 Decimal，不逐项舍入。

匹配规则
商品基础信息 C 列 SKU ID；优先 E 列 SKU货号，空白取 D 列 SKC货号。商品与成本货号均取开头6位数字，保留前导零，例如065091-ECCPP→065091；截取后对应多个成本记录仍提示异常。
按订单号 + SKU ID 匹配两张结算表。真实合并单元格按合并区域读取锚点数据，不凭空填充缺失币种。
同订单同SKU同时出现在两表时，优先已结算，不重复计入；同状态同币种同单价的结算多行合并件数，源行保留供核对；同状态单价不一致仍提示异常。
订单表同一订单+SKU只作为一次筛选，不重复计利润；去重和合并过程写入“处理提示”，不再混入未计入订单数。
成本使用 TEMU-半托管 定价表的 A列SKU，R/S/T/U/AB/AC列对应成本参数。
读取 Excel 已保存的公式缓存；空缓存作为异常，不使用零替代。请在 Excel 中更新公式并保存后重新导入。
不同币种分别汇总；工具不换汇，成本金额须与申报价格保持相同货币单位。
只使用用户主动选择的文件，不修改源文件，不上传数据。

异常记录不包含在利润合计中。合计仅代表成功匹配的部分，请先检查异常清单。
当前针对提供的五张表结构开发；将来平台改变列布局时需更新适配。

拖拽权限修复：工具启动时自动使用当前资源管理器的普通用户权限，避免管理员程序无法接收资源管理器拖放。
云端更新：点击“检查云端更新”，发现新版本后可确认下载、校验并重启安装。已发布的修复可直接获取；尚未修复的问题不会自行消失。更新仅访问公开程序发布库，不上传订单、成本或利润报告。


6.1.0：稳定目录版，完整解压ZIP后运行ProfitTool.exe；不要单独移动EXE，必须保留_internal目录。旧单文件版本请改用桌面已更新的快捷方式，不通过旧更新器迁移。

6.1.1：结算表按表头识别，兼容SettledParentFlow/SettledFlow/UnsettleFlow；明细交易只将销售回款用于件数和申报价计算，运费仍手填。商品信息支持基础信息或产品价格导出表（SKU ID、SKU货号/货号，空时SKC货号）。全部失败时不显示最终利润。

6.2.0估算规则：结算价格及币种有效时，缺商品/成本的记录按申报价格×10%×件数估算；缺件数则仅按申报价格×10%，单列估算依据，不把件数填成1。未找到结算、缺申报价/币种、件数非法或结算冲突仍异常。正常/估算利润分别展示并合计；运费仅加一次。

6.2.1记录保存：已选文件、日期月份、运费/退款参数、计算结果及日志自动保存在本机LOCALAPPDATA/ProfitTool，更新或退出重开可恢复；清空记录按钮清除计算结果与日志，保留文件和参数。不上传业务记录。
