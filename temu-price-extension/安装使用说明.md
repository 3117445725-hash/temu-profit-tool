# Temu 订单申报价格采集扩展 · 测试版 0.1.0

目前提供 Chrome / Edge 的 Manifest V3 扩展包。QQ、夸克等 Chromium 浏览器若支持加载 MV3 解压扩展，可尝试安装，但尚未逐浏览器验证。Firefox、Safari 不适用此安装包。

## 安装

1. 完整解压 ZIP，保留 `manifest.json`、所有 JS 和 popup.html。
2. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
3. 在扩展管理页启用开发者模式，选择“加载已解压的扩展程序”，选中本目录。
4. 安装后刷新已登录的 Temu 订单页面，再打开扩展。

## 先做一笔验证

打开一笔订单详情，点击扩展的“读取当前详情”，导出价格表，核对订单号、SKU、件数和单件申报价格是否与页面一致。

截图中的“申报价格”按用户确认的单件价格读取，不乘件数写入价格列。数量不明确则留空；不会从其他商品卡片借数量。

## 批量采集

1. 在平台自己选好店铺、订单创建月份和订单状态，回到订单列表。
2. 扩展中选择相同月份，点击“采集当前筛选列表”。
3. 扩展只点击文字为“订单详情”的入口，读取对应订单/SKU 后返回列表；若平台打开了新标签，读取后关闭该任务打开的详情标签。
4. 默认只处理当前列表页。若要翻页，可勾选自动下一页；只有唯一、明确、未禁用的“下一页”入口才会点击。找不到入口会停止，可手动翻页后再次开始。
5. 遇到登录、验证码或页面超时会暂停，人工处理后点击“继续”。支持本浏览器本地保存和断点续采。

## 导出与利润工具

- **价格表**：含订单号、SKU ID、货号、件数、单件申报价格等。与原订单表一起上传利润工具，可补齐历史价格。
- **订单表**：另含订单创建时间。创建时间成功读取时，可作为订单来源，搭配成本表计算。
- 不要同时把两份完整订单表作为订单来源，以免月份/订单范围出现歧义。
- 价格按订单号＋SKU保存，不按SKU单独套用历史价格。同一组合价格冲突会保留旧值并提示。
- 采集日期月份与所选月份不同时，不保存该订单；没有读到创建时间时无法自动核验月份，应人工核对平台筛选。

## 数据和限制

只使用你当前已登录的浏览器页面。权限限指定 Temu 商家域名、标签页、本地存储和导出下载；不读取Cookie，不上传业务数据，不点击发货、确认、运单、付款等按钮。

每个浏览器的登录状态与采集记录各自独立。清空采集记录仅影响本扩展本地数据，已导出的CSV不删除。
